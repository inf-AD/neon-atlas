# NEON ATLAS — квиз «страна ↔ столица»

Мини-игра для урока: учитель открывает страницу, ученики по очереди соотносят
страну и её столицу. На каждой плашке — изображение-ассоциация с городом
(Эйфелева башня, Колизей, Пирамиды Гизы и т. д.).

Стиль: киберпанк, неон, плашки-карточки. Все иллюстрации — встроенный SVG,
внешних файлов и шрифтов нет: страница работает офлайн.

## Играть

Открыть **https://inf-AD.github.io/neon-atlas/**

Правила на экране: выбрать страну слева, затем столицу справа. Верная пара
загорается зелёным, ошибка не отнимает пару, но считается. Клавиши:
`H` — подсказка, `R` — сброс, `N` — новый раунд.

## Как устроено

```
index.html   статическая сборка (её и отдаёт GitHub Pages)
style.css    оформление
game.js      механика раунда: выбор, проверка, таймер, итоги
src/         исходники на PHP — то же самое, но раунд собирает сервер
```

`src/` не нужен для игры на Pages: это исходники. PHP-версия полезна, если
хочется менять пары и не пересобирать страницу вручную.

### PHP-версия локально

Нужен PHP 8+. В папке `src/`:

```
php -S 127.0.0.1:8080
```

затем открыть <http://127.0.0.1:8080/>. В Windows проще запустить
`src/start.bat` — он найдёт PHP сам и откроет браузер.

### Пересобрать статическую страницу

```
cd src
php build_static.php
```

Скрипт запишет `index.html` в папку `src/`; скопируйте его в корень репозитория.

## Данные

16 пар «страна → столица → достопримечательность → короткий факт» лежат в
`src/data.php`. Раунд — 6 пар, выбираются и перемешиваются случайно.
